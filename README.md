# MORT

MORT is a MOtorized RoboT with a tank chassis, powered by Zephyr RTOS on an STM32G0 microcontroller
aboard a custom PCB. MORT is battery powered, controlled remotely via an IR remote, and has various
forms of external expression including LEDs and a buzzer.

This project is my effort to bring a professional approach to the design and implementation
process, and an excuse to expose myself to concepts such as CI/CD, professional Git and GitHub
usage, project documentation and PCB design.
